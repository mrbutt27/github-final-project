# Simple Interest Calculator

## Description
A simple Bash-based calculator application that computes simple interest 
based on user input for principal amount, rate of interest, and time period.

## Prerequisites
- A Unix/Linux terminal
- Bash shell installed

## Installation
git clone https://github.com/mrbutt27/vftvk-Simple-Interest-Calculator.git
cd vftvk-Simple-Interest-Calculator

## Usage
Run the script and enter the required values when prompted:
./simple-interest.sh

You will be asked to input:
- Principal amount
- Rate of interest
- Time period (in years)

The script will calculate and display the simple interest.
